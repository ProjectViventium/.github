# Security Policy

## Reporting a Vulnerability

For any sensitive security issue in a ProjectViventium repository, use GitHub's private vulnerability reporting in the affected repository's **Security** tab.

Do not open a public issue for exploit details, credentials, or other sensitive security material.

If a repository does not expose private vulnerability reporting for some reason, open a normal issue only for non-sensitive hardening discussion and avoid including exploit details.

## Scope

This policy applies to repositories under the `ProjectViventium` GitHub organization unless a repository documents a stricter local policy.

## Response Expectations

ProjectViventium will aim to acknowledge valid reports within 5 business days and follow up with triage status and remediation planning as appropriate.
